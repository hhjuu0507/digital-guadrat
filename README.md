# 방형구 식물 조사 결과 (열람 전용 사이트)

저장해 둔 엑셀 결과를 같은 화면으로 보여주는 **정적 사이트**입니다.
서버·API 키·데이터베이스가 없어서 무료 정적 호스팅에 올려 두면 오래 유지돼요.

## 폴더 구성

```
site/                 ← 인터넷에 올리는 폴더 (이것만 올리세요)
  index.html, style.css, app.js
  data.js             조사 데이터 (이름·학번 일부 가림 처리됨)
  results-masked.xlsx '엑셀 다운로드' 버튼용 파일 (이름·학번 일부 가림 처리됨)
  robots.txt          검색 엔진에 노출되지 않도록 요청
tools/build_data.py   엑셀 → data.js 변환 스크립트 (데이터가 바뀔 때만 필요)
```

## 내 컴퓨터에서 먼저 보기

`site/index.html` 파일을 더블클릭하면 브라우저에서 바로 열려요.

## Netlify에 올리기 (무료, 가장 간단)

1. https://app.netlify.com/drop 으로 가요.
2. **먼저 가입/로그인**하세요. 로그인 없이 올리면 임시 사이트로 올라가 곧 삭제될 수 있어요.
3. `site` 폴더를 화면에 끌어다 놓으면 `https://○○○.netlify.app` 주소가 생겨요.
4. 사이트 설정에서 주소 이름을 원하는 걸로 바꿀 수 있어요.

> Netlify 화면 구성과 무료 플랜 조건은 바뀔 수 있어요. 막히면 같은 `site` 폴더를 GitHub Pages나 Cloudflare Pages에 올려도 똑같이 동작합니다.

## 1년 동안 유지하려면

- 올린 뒤 **가끔(한 달에 한 번쯤) 주소로 접속**해서 잘 열리는지 확인하세요.
- 이 폴더 전체와 **원본 엑셀을 따로 보관**해 두세요. 사이트가 사라져도 `site` 폴더를 다시 올리면 몇 분 만에 복구돼요.
- 공모전 제출 전에 **다른 기기·시크릿 창에서 주소가 열리는지** 꼭 확인하세요.

## 개인정보 가림 규칙

| 원본 | 사이트·엑셀에 표시 |
|---|---|
| 10234 홍길동 (예시) | 102** 홍○동 |
| 10234 (이름 없이 학번만, 예시) | 102** |
| 3명이 함께 제출 | 학생마다 각각 가림 |

- 가림 처리는 변환할 때 이미 끝나서, 사이트 파일(`data.js`, 엑셀)에는 **원본 이름과 학번이 들어 있지 않아요.**
- 그래도 주소를 아는 사람은 누구나 볼 수 있어요. 공모전 제출처에만 알려 주세요. (`noindex` 설정으로 검색에는 잘 나오지 않게 해 뒀어요.)
- 원본 엑셀(실명 포함)은 `site` 폴더에 넣거나 인터넷에 올리지 마세요.

## 데이터를 고치거나 새로 만들 때

Python 3와 openpyxl이 필요해요 (`pip install openpyxl`).

```bash
python3 tools/build_data.py  원본.xlsx  site
```

- 가림이 제대로 됐는지 스스로 검사하고, 원본 이름이 남아 있으면 오류를 내고 멈춰요.
- 엑셀의 '제출 일시'가 UTC로 저장돼 있어서 한국 시간(+9시간)으로 바꿔 표시해요. 엑셀 시간이 이미 한국 시간이면 `tools/build_data.py` 위쪽의 `OFFSET`을 `hours=0`으로 바꾸세요.

## 참고

- 엑셀에 사진이 없어서 방형구 사진은 표시되지 않아요.
- 식물 이름과 초록색 비율은 AI가 만든 **참고용 값**이에요. '미확인 식물'에 붙은 학명은 가장 가까운 추정값이고, 일부는 종 상태가 '확인됨'으로 기록돼 있는데 원본 데이터 그대로 표시했어요.
- 원본의 '피도 등급(학생 관찰)' 열은 전부 '미입력'이라 화면에는 표시하지 않았어요. (엑셀 다운로드 파일에는 그대로 있어요.)
